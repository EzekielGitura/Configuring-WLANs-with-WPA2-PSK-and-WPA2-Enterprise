# Configuring WLANs with WPA2-PSK and WPA2-Enterprise 🔒🌐

## Welcome to My WLAN Configuration Adventure! 🚀

In this project, I explored the world of **Wireless Local Area Networks (WLANs)** by configuring a Wireless LAN Controller (WLC) with two distinct authentication methods: **WPA2-PSK** and **WPA2-Enterprise**. Using **Packet Tracer**, I set up VLAN interfaces, configured SNMP for monitoring, and created a DHCP scope for wireless management. If you’re curious about how to secure and manage wireless networks, this guide will walk you through my journey step-by-step.

---

## What Was I Doing? 🤔

This assignment focused on designing and securing a wireless network using industry-standard practices. Here’s what I tackled:
- **Configuring VLAN Interfaces**: Created VLANs for different WLANs to segment traffic.
- **Setting Up Authentication Methods**:
  - Configured **WPA2-PSK (Pre-Shared Key)** for small-scale networks like home offices.
  - Enabled **WPA2-Enterprise** for robust, centralized security suitable for larger environments.
- **SNMP Integration**: Added an SNMP server to monitor the Wireless LAN Controller (WLC).
- **DHCP Scope**: Defined a DHCP range for wireless devices to obtain IP addresses dynamically.
- **Device Connectivity**: Ensured all devices were properly authenticated and connected securely.

Through hands-on exercises, I gained practical experience in managing wireless networks, securing devices, and troubleshooting connectivity issues.

---

## Tools Used 🔧

1. **Packet Tracer**: Simulated a real-world wireless network environment for configuration and testing.
2. **Wireless LAN Controller (WLC)**:
   - Accessed via a web browser using credentials (`admin/Cisco123`).
   - Configured VLANs, WLANs, and authentication methods.
3. **Authentication Protocols**:
   - **WPA2-PSK**: Simplified security using a shared password.
   - **WPA2-Enterprise**: Enhanced security using a RADIUS server for user credential management.
4. **SNMP Server**: Integrated for monitoring and managing the WLC.
5. **DHCP Configuration**: Set up a scope to assign IP addresses to wireless clients.
